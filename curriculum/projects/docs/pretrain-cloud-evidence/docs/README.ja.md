# Ticket 19：承認済みクラウド GPU 事前学習の証拠

これは既存の再開可能な小型モデルプロジェクト `projects/pretrain` のクラウド拡張です。今回の成果物は**準備済みだがブロックされた証拠パッケージ**であり、クラウド実行の主張ではありません。`evidence-package.json` では provider、GPU、経過時間、指標、支出を意図的に `null` としています。

## 有料実行前の承認ゲート

人間が provider、リージョン、GPU 形状、モデル/データ/ランタイムの前提、25 USD の上限、停止方法を明示的に承認するまで、GPU のレンタル、データのアップロード、有料ストレージの作成をしてはいけません。申請文は `approval_gate.request_text` にあり、承認には範囲、承認者、時刻が必要です。認証情報、アカウント ID、リソース ID、非公開 provider ページはリポジトリに入れません。

提案レシピは `cloud-run-config.json` の 4 層・4 ヘッド・64 次元モデル、`tinyshakespeare.txt`（ハッシュ記録済み）、Python >=3.10、PyTorch >=2.0 です。開始前に正確な CUDA/ドライバ版を記録します。理論見積りは GPU 2 時間とストレージ 5 GB 日ですが、provider の見積り、クォータ、税、最低料金、請求遅延を承認前に確認します。無料枠は仮定せず、provider 側の強制ハード上限も保証しません。

## 承認後の実行と復旧

承認後、git、設定/データのハッシュ、イメージダイジェスト、CUDA/ドライバ版、GPU ID を非公開ログに記録し、証拠パッケージのコマンドを実行します。上限到達、ヘルスチェック失敗、または計画終了時に計算資源を停止/解放します。ストレージを残す場合は承認を取り、継続課金を報告します。破壊的削除には別の確認が必要です。

チェックポイント（例：step 200）の後で中断し、`latest.pt` を消さずに同じ目標へ `--resume auto` で再開します。独立プロセスで `evaluate.py` を検証用分割に対して実行します。報告には中断/再開ステップ、独立 loss/perplexity、失敗事例、経過時間、GPU ID、実際の請求スナップショットを含めます。

## 証拠の規律

理論値は設定と provider 見積りから、測定値は承認済み実行からのみ得ます。CPU スモークテスト、合成ログ、価格ページを測定値として記入してはいけません。

```sh
PYTHONPATH=. python3 -m unittest discover -s tests/unit -p 'test_cloud_evidence.py'
```

この決定的テストはメタデータ契約だけを検証し、クラウド/GPU の証拠ではありません。承認と実行記録が得られるまで、Ticket 19 の実行受入れは未達です。
