# Study Days 01–03 review record

**Review revision:** 2026.10.30-rev1
**Scope:** `day-01`, `day-02`, and `day-03`; English, Simplified Chinese, Traditional Chinese, and Japanese editions.

## Per-lesson findings

- **Day 01** retains the existing mutation example as the shared tracer bullet. It is extended with a diagnostic self-check, prediction before execution, concept decomposition, terminal/environment verification, one selected-agent exercise, retrieval, and explicit recovery. The example is referenced by later activities rather than copied.
- **Day 02** moves from the tracer evidence to concept decomposition and minimal reproductions. The selected-agent task is bounded by context, permissions, budget, review, retry, and an assistance declaration. A separate independent terminal/filesystem task requires a created artifact and command output without AI assistance.
- **Day 03** deliberately introduces a recoverable path/environment failure, requires prediction and diagnosis before help, then separates agent-assisted review from an independent filesystem mastery check. The final activity is spaced retrieval plus a recovery plan, not hidden extra time.
- Each ledger contains 480 active minutes. Review, recovery, and assessment are counted inside that total; breaks and unattended runtime are not counted.

## Language-edition review

All four editions contain the same stable activity IDs and the required fields: objective, prerequisites, instructions, exercise, hint, answer, assistance policy, and mastery criterion. Navigation and learner-facing titles are localized in each edition. Commands, file names, and policy distinctions remain invariant where they are executable or safety-critical. The editions are structurally equivalent; this deterministic review does not claim native-speaker certification.

## Source and rights review

Day 01 keeps the existing Python documentation attribution and compared-candidate decisions. New Day 02–03 material is original course text and links no imported transcript or video. Optional external media remains non-blocking because every required instruction, exercise, hint, answer, and mastery criterion is present locally. Source availability and external-agent access are not represented as local test evidence.

## Acceptance limits

The deterministic ledger and structural/browser checks validate content shape, active-time accounting, language parity, navigation, and disclosure behavior. They do not prove a learner's mastery, live OAuth, paid agent access, cloud training, production deployment, or human translation review.
