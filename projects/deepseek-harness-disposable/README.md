# DeepSeek Harness disposable fixture

This tiny fixture is safe for a bounded learner exercise. It is not a transcript from DeepSeek Harness and contains no API key. Copy it to a temporary directory before any agent run. The requested change is limited to `src/greeter.py`; do not modify tests, dependencies, deployment files, parent paths, or network configuration.

Run independently with:

```sh
python3 -m unittest discover -s tests -v
```
